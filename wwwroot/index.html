About Ferron

Ferron is a web server and reverse proxy built for production environments where reliability and debuggability matter. It gives a robust foundation for serving content and managing complex routing with minimal configuration overhead.

By focusing on ease of setup and ease of debugging, Ferron ensures that your infrastructure remains predictable under load and transparent when it matters the most.

If you're visiting this page, it means the server is active but the webroot directory is currently empty.

Installation complete

The Ferron web server is successfully installed and running. You can now deploy your website content to the webroot directory:

/var/www/ferron (Linux)
C:\Program Files\Ferron\wwwroot (Windows)

Configure your server using the official documentation. The configuration file is typically located at:

/etc/ferron/ferron.conf (Linux)
C:\ProgramData\Ferron\ferron.conf (Windows)
